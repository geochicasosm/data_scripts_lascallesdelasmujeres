## Getting Started

The data displayed in the [#LasCallesDeLasMujeres](https://geochicasosm.github.io/lascallesdelasmujeres/) project is generated by running the scripts contained in this project. Below are the instructions to reproduce the process and generate data for any city.

### Installation and environment setup

To download the project and run the scripts, you need to have installed:

- GIT (Download [HERE](https://git-scm.com/downloads))
- Node.js version >=12 (Download [HERE](https://nodejs.org/download/release/v0.12.0/))

Download the project:

```
git clone https://github.com/geochicasosm/data_scripts_lascallesdelasmujeres.git
```

Package installation:

```
npm install
```

# Instructions

### _Step 1_: Identify the city and its relation in OSM

Search [HERE](https://www.openstreetmap.org/relation/11) for the OSM ID of the city to process.

Create a folder inside the project's "data" folder, with the name of the city to process, in lowercase and without spaces. Examples:

**barcelona**

**sanjose**

**buenosaires**

### _Step 2_: Download data

Execute:

```
npm run initial-step -- --city=cityname --relation=relationID
```

- Example: **npm run initial-step -- --area=[2.0875,41.2944,2.2582,41.4574] --city=barcelona --relation=347950**

The following files are generated:

- cityname_streets.geojson
- list.csv
- list_genderize.csv

### _Step 3_: Remove streets without gender and search for Wikipedia links

Apply the script that removes streets classified as "unknown" (neither woman nor man) and searches for Wikipedia articles for streets named after women:

```
npm run wikipedia-step -- --city=cityname
```

_\*To disable automatic removal of "Unknown" streets, use the `--keepUnknown` flag_

The file 'list_genderize_wikipedia.csv' is generated.

### _Step 4_: Manual review

Manually review the previous file:

- Remove streets that are not named after people
- Correct errors in the male/female classification. The reliability factor is 2,-2 (Woman,Man).
- Correct and add Wikipedia links (streets with male names do not need a link)

---

#### Criteria for removing or keeping streets:

_REMOVE_ if:

- It refers to flora or fauna
- It refers to historical moments (The Battle of Pavón)
- It refers to inanimate objects (Esmeralda = Argentine Ship)

_KEEP_ if:

- It bears the name of a female saint
- It bears the name of a female deity with a woman's representation (Venus)

---

Save the corrected file in the same project folder, with the name:

**cityname_finalCSV.csv**

_ATTENTION_: It is very important that the field separator used in the CSV is ";", otherwise it will not work.

### _Step 5_

Execute:

```
npm run final-step -- --city=cityname
```

Three files are generated:

- **final_tile.geojson** Final file that will be loaded on the map
- **stats.txt** File with data statistics
- **noLinkList.txt** File with the list of streets without a Wikipedia article

### Using `just` to run the scripts

With [just](https://github.com/casey/just) installed, you can run these steps more easily:

```bash
#List the different steps
$ just -l
just -l
Available recipes:
    create_dir city               # Creates the data directory
    download_data city relationID # Downloads the city data from the Overpass API (creating the directory first)
    postprocess city              # Finish the process
    process city relationID       # Run download_data and wikipedia recipe
    wikipedia city                # Enriches the CSV with wikipedia details
---
```

The `process` step automatically calls the `download_data` and `wikipedia` steps

```bash
$ just process aldaia 340328
...
```

And once the data is ready, you can call the `postprocess` step to finish the process

```bash
just postprocess aldaia
⚙ Finishing the processing of aldaia
npm run final-step -- --city=aldaia

> lascallesdelasmujeres_data_scripts@1.0.0 final-step
> node ./scripts/parse_final.js --city=aldaia

tar czf data/aldaia.tar.gz data/aldaia
File ready for submission.

👉 data/aldaia.tar.gz 👈

 🌈 Thanks!! 🌈
```
